# 美术设计规范

完整方向见 `PROJECT_BIBLE.md`。

## 视觉目标

《回路》应像“真实中国城市夜间抢修现场，被某种无法解释的东西轻微改写”。

## 背景

- 半写实 2D / 2.5D。
- 重点画旧小区、供电所、配电房、楼道、架空线、巷道、城中村、拆迁区等真实空间。
- 画面允许脏、潮、暗，但必须能读清交互信息。
- 雨、水渍、锈蚀、胶布、编号贴纸、褪色门牌属于高频材质语言。

## 人物

- 手绘立绘，成年人的真实身形比例。
- 避免过度萌化、夸张大眼、校园偶像式服装。
- 工作人员服装与工具要有职业可信度，但不照搬现实企业 Logo。
- 表情恐怖优先靠“细微不协调”，少用裂嘴、黑眼、满脸血等直接符号。

## UI

- 横屏，底部半透明叙事框，不遮挡关键画面。
- 工单、证据、台账、手机、仪表读数可以成为界面层。
- UI 主色：煤黑、青灰、脏绿、旧纸黄。
- 警示色：低饱和暗红，只用于危险或异常。

## 镜头与构图

- 多用固定机位、长走廊、远处单一光源、被门框/电箱切割的画面。
- 恐怖主体不要总放在视觉中心。
- 留黑和留空是构图资源。

## 禁用倾向

- 纯红黑“鬼屋海报感”。
- 全程 VHS 滤镜。
- 过量颗粒与故障艺术导致信息不可读。
- 日式神社、鸟居等与本土空间不相干的视觉捷径。

## v1.0.1 实际制作规格

- 六幅场景使用图像生成能力逐幅重绘，保留原场景的固定机位与关键物件位置；采用 1600 × 900 的 WebP 交付。
- 六名人物逐人生成，使用老周作为笔触与光影基准；交付 640 × 960 的透明 WebP，保留真实 alpha 通道。
- 场景以旧雨巷美术为材质基准，人物使用偏暖左侧光与偏冷阴影；年龄、耳麦、帽子、钥匙、眼镜和折纸等角色特征保持可辨认。
- 应用图标延续断开的圆环与暗红闪电，以同一生成源输出网页 PNG、PWA 192 / 512 图标及 Windows ICO。
- 提示词、参考来源与成品 SHA-256 记录在 `art/redraw-manifest.json`。不宣称工具未暴露的模型型号；不使用生成图片承载解谜文字、仪表读数或交互按钮。
- 旧 SVG 与原雨巷 PNG 由 Git 历史保留，发布包使用新美术。动态城市线路图仍由程序根据归档进度绘制。

## v1.1.0「巡城师徒」规格

- 程砚32岁、季宁23岁采用深蓝与低饱和暗橙抢修服，反光条、长袖、白盔与黄盔的下颏带完整。程砚佩电台，季宁持平板与记录册，轮廓和道具可辨认。
- 同一身份参考生成专注与警觉表情，640×960透明WebP。老周另有白盔、长袖反光雨衣的现场版本，室内档案形象保留。
- 新增1600×900抢修车背景：两张空前座、固定工具箱、终端、雨窗与热水杯，为师徒出车、核对和回程提供重复出现的共同空间。
- 八名角色都有640×640的Q版全身形象，以程砚为比例和笔触母版。用在人物目录，叙事现场使用成年立绘。
- 联络在场方式分为现场、通讯卡和旧档照片。林岚远程联系不画成站在作业点，许守成显示2019年旧档标记。
- 本轮14项美术的提示词、参考与校验值见art/patrol-manifest.json；目前共七场景、八基础立绘、三变化立绘和八Q版。
- 生成画面负责形象和氛围，工单、图例、测量和解谜文字由应用叠加，不要求AI图片准确绘制数字。

## v1.3.0《应声》场景

旧通信间使用物业夜班室作为笔触、材质与光色参考，通过内置图像生成制作新空间。左侧旧电话、桌面档案盒与右侧闭合通信柜可辨认；下方留暗给正文，中心窄门不放人物或显形鬼怪。输出1600×900 WebP，原PNG与完整提示词、参考SHA-256登记在art/answering-manifest.json。谜题文字与热点继续由应用叠加。

## v1.4.0《来访》

旧回迁接待站延续旧通信间的湿绿暗色、暖台灯与写实笔触，玻璃服务窗、旧播放设备、门牌木背、取号机、空椅和侧门可辨认，不画具象鬼怪。输出1600×900。罗禾警觉表情以原身份参考编辑，低马尾、蓝衬衣、橄榄外套、值班册和三把钥匙保持，640×960真实透明WebP。生成提示词、原PNG、参考与成品校验见art/visitors-manifest.json。
