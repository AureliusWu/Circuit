# 原创素材目录

本目录记录《回路》当前版本使用的场景与人物美术。以下 SVG 为本项目新绘制的原创矢量插画，创作与整理：项目开发过程中的 Codex 美术实现；未引用外部图片、字体文件、商标、企业标识或第三方素材包。素材归属随项目，本文不另行指定项目或素材许可证。

场景采用 1600 × 900 横屏画幅，人物采用 420 × 640 透明半身画幅。文件只含静态 SVG 图形、渐变与图案，不执行脚本，也不加载远程资源。画面遵循 `ART_BIBLE.md` 的煤黑、青灰、脏绿与旧纸黄主色，异常只使用少量暗红。

人物按成年人的头肩比例绘制，面部通过墨线、平缓肤色阴影、眼周细纹与领口结构表现差异。所有角色为虚构人物，不以真人照片作为来源。

## 接入与维护

场景由 `.stage-background` 全画幅呈现，人物由 `.character-portrait` 显示。`src/release.css` 放在基础与调查样式之后加载，负责发布界面的主菜单、章节选择、现场人物、谜题提示、地图档案、设置、存档与结局摘要。故事提供原始坐标与热点顺序；响应式按固定槽位保留位置，已收集标记消失后，其余标记不会挪动。图形不承载可点击按钮或关键解谜文字。

故事和界面文本仍由应用层提供，背景中的配电图标签属于场景装饰。后续替换素材时保留稳定路径和画幅，检查横屏 960 × 540、760 × 430 与竖屏 390 × 844 下的热点、文字、叙事框和弹窗可读性。弹窗和较小屏幕上的长叙事允许滚动；减少动画与高对比设置由应用类名控制。

## 验证

所有文件经过 XML 解析检查；素材不含 `script`、远程 `href`、字体导入或外部图片引用。SVG 为可直接维护的源文件，不依赖付费绘图软件或在线转换服务。
