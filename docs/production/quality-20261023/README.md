## 使用与边界

本目录 `media-review.html` 可在完整仓库内直接打开，按场景、人物、关键词与标记筛选。在线素材模式读取固定提交的原始素材；本地模式使用当前仓库。试听、通过/需修改标记及备注只写入本工具独立的本机记录，可导出 JSON；它们不修改游戏存档或自动改写人工验收。导入拒绝版本、目录摘要或素材 ID 不一致的记录。

ASR 沿用录制时的证据，未重新识别；精确同音复核单独显示，避免把同音字当作错读。信号 RMS、采样峰值不等于 LUFS / 真峰值。透明边缘、静音与语速仅用于审阅排序。全部背景、CG、角色图与保留参考图逐文件解码和测量；真实场景构图、情绪、混音、实体设备和有效阅读计时继续集中待用户操作。

工具来源：[Circuit 质检工具](https://github.com/AureliusWu/Circuit/blob/main/tools/production/audit_media_quality.py)。报告为发布后只读质量检查，不替代原版 Windows / PWA 运行凭据。
