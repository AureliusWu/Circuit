# v1.1.0「巡城师徒」发行记录

程砚明确成为梧城电网有限公司配电运检中心城区抢修班员工，固定徒弟季宁随队参与六章。主角九年电网经历、城区班两年；他熟悉事故通报，本轮才接触缺失的住户原件。季宁从核对照片索引成长到终章主动完整读回交接，两人有出车、分饼干、核对回执和吃热饭的共同生活片段。

## 美术与演出

本轮使用图像生成新增14项资源，已实际接入：

- 程砚、季宁基础透明立绘与专注、警觉表情。
- 老周的白盔、下颏带、长袖反光雨衣现场立绘。
- 八名人物的Q版全身形象和可切换的“人物与抢修队”目录。
- 抢修车背景，用于出车、对时、纸质台账核对与回程。
- 远程联络显示通讯卡，许守成显示带2019标记的旧档照片；卡片身份条在四种布局中避开叙事框。

当前为七场景、八基础立绘、三变化立绘、八Q版及统一应用图标。26幅WebP插画约3.52 MiB。[美术预览](art/patrol-contact-sheet.jpg)、[立绘目录](art/characters-portrait-preview.jpg)、[Q版目录](art/characters-chibi-preview.jpg)、[抢修车演出](art/patrol-van-preview.jpg)和[通讯卡](art/patrol-radio-preview.jpg)可直接查看。

## 剧情合理化

六章重点改写122个叙事节点，另校正证据和展示标记：

- 在线提示、物理测量和旧档队列分开；钳形表不直接判断功率方向。
- 电网侧、用户家电、物业公共设施按产权与任务分工，正常供电具备条件后及时恢复。
- 季宁不单独执行未知操作或专责监护；作业人员与工作负责人按当班安排到齐。
- 救援旁路说明为独立供电的临时照明；地图虚线是跨供电分区的救援与交接路线。
- 沈衡2019年平安返程，近日于2026年去世；当前头七与七年前许守成事故分开。
- 杨婶知道许守成遇难，留灯执念与未收到巡查交接有关；获救居民继续真实生活。
- 错误建议在执行前被提出复核，后果保留误分类、误结工单与责任错接。
- 今天接收原件和责任说明，保留2019空白；老周的离岗、虚假完成及未交材料接受独立复核。
- 正式调查、家属意愿和未知源端后续查明各有边界，异常变化只记录局部关联。
