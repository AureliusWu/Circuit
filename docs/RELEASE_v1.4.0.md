下文保留 2026-10-13 的内容制作与原始验收记录；2026-10-15 的检索/面板集成另见 [集成记录](production/VISITORS-INTEGRATION.md)。

《应声》归档后，D3把调查带到城南旧回迁接待站。程砚与季宁先按正式报修处理站外低压接入点缺陷，再依产权方授权核窗口两联、输入卡与旧采集任务。陈伯开管理侧门，罗禾提供新苑移交原册；两人的实际职责、2019旧档与今晚到场记录分别核实。

新增第九章《来访》：39节点、4,499个非空白正文字符、5条现场记录、两轮调查与两个可重试错误结局。全作九章386节点、45条现场记录、42,833个非空白正文字符。新章找到D3的实际输入卡和可复现传送路线，完成当前接收与停用；新句子的最初录制者仍无充分证据。旧门牌、复写蓝印、窗口空椅与湿脚印承担民俗悬疑，陈家认门讲究不作为统一驱除规则。

现场记录新增“并排核对”：取得两条记录后可挑两份比较，选中另一栏的记录会交换位置。只显示本章已收集内容；电脑两栏，手机上下排列。列表默认仍展示全部已收集记录。查看、选择和录音重听不写自动或手动存档，关闭面板后焦点回到入口。
