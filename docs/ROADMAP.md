# 《回路》开发路线

## v1.1.0 — 巡城师徒

程砚与季宁成为固定城区抢修队伍，六章职业分工、时间线和交接范围完成合理化。新增八角色Q版目录、师徒表情、老周现场防护立绘和抢修车场景。详见[本轮发行记录](RELEASE_v1.1.0.md)与[剧情合理化说明](STORY_RATIONALIZATION.md)。

## v1.0.1 — 全量美术重绘

6 幅场景、6 名人物与应用图标已通过图像生成重绘并接入，透明立绘与全量离线缓存完成。详见 [重绘发行记录](RELEASE_v1.0.1.md)与[素材目录](ASSETS.md)。

## v1.0.0 — 第一部 / 归档闭合

六章主线已经实现：《十三户》《头七》《回送》《长明》《零线》《闭合》。详见 [发行记录](RELEASE_v1.0.0.md)。

- [x] 六章独立调查与推理，共 268 个剧情节点
- [x] 每章两个错误结局与标准结局，终章回应救援事故
- [x] 老周、林岚通讯和住户关系；七年前工单与旁路证据
- [x] 30 条现场记录、六段城市线路档案和章节解锁
- [x] 六幅原创场景、六名人物立绘与程序合成音画
- [x] 自动阅读、文字速度、音量、静音、高对比、减少动态效果
- [x] 自动进度、三个手动槽、旧版兼容与 JSON 导入/导出
- [x] 抢修日志、键盘、横竖屏和焦点管理
- [x] PWA 离线预缓存所有场景、人物及应用文件
- [x] 剧情图、存档、设置与六章战役测试
- [x] 固定依赖、Web 发行 ZIP 与校验和、Windows NSIS 构建工作流

原路线对序章提出 30–45 分钟、后续章节提出 30–60 分钟的扩写目标。本版采用完整的中短篇结构，按实际节点、正文和可玩路径记录规模；这些时长目标未经真人测定，不作为本版达标声明。
