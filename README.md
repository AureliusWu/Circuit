# 回路 / Circuit

> 中式民俗恐怖叙事 AVG · PWA + Windows 桌面端

《回路》是一款以城市配电故障抢修为入口的中式恐怖游戏。玩家扮演 **梧城供电公司基层配电运检员**，在夜间停电、跳闸、漏电、异常电流与旧城区抢修任务中逐步发现：某些“故障”并不属于电气系统。

## 当前版本

**v0.1.0 · 闭合前**

这是项目的第一个可运行原型，目标是验证：

- 16:9 横屏叙事界面
- Visual Novel + 场景调查 + 轻解谜
- “电气故障 → 现场排查 → 民俗异常 → 技术/仪式双重推理”的章节循环
- PWA 浏览器运行
- Tauri 2 Windows 桌面端
- 单主角 + 每章不同关键人物的单元剧结构

## 核心设定

主角是梧城供电公司基层配电运检员，兼参与故障抢修。白天处理普通线路缺陷，夜间值班时则会接到一些无法被台账、图纸和仪器解释的故障。

项目坚持一个规则：**每个异常最初都必须能被解释成电气问题。**

例如：

- 一户空置多年的老宅持续产生稳定负荷；
- 已拉开的隔离开关仍有“下游来电”；
- 停电片区中只有一盏路灯始终亮着；
- 电表记录里出现不存在的第十三户；
- 同一条线路每逢头七固定跳闸。

## 游戏形态

- 类型：中式民俗恐怖 / 悬疑 / 叙事 AVG
- 画面：2D / 2.5D，手绘人物 + 半写实现实场景
- 媒介：旧照片、工作票、台账、聊天记录、监控截图、仪表读数、低清数码影像
- 结构：单主角；章节式单元剧；偶尔短暂切换视角
- 玩法：视觉小说骨架 + 场景热点调查 + 证据收集 + 轻量线路/仪式推理
- 平台：PWA + Windows 桌面端
