# 《回路 / Circuit》项目圣经 · v1.1.0

## 定位

一款以梧城城区电网抢修为入口的中式民俗悬疑 AVG。夜班出车、住户报修与城市日常中出现不合常理的细节，玩家通过实测、原图、时序与证词逐项推理。民俗讲究和灵异现象参与事件，不用章末感言替代悬疑。

## 固定主角与队伍

玩家始终扮演 **程砚，32 岁，梧城电网有限公司配电运检中心城区抢修班员工，九年现场经历**。负责获准范围内的城区配电故障排查、供电核验和工作交接。

**季宁，23 岁，固定队友与徒弟**。入班八个月，已完成岗位培训，在程砚指导下跟班。记录、终端核对、时标与图纸比较、住户联络是她的主要分工；不独立操作未知开关、不单独承担专责监护。她有观察、提问和纠正师傅判断的能力。

老周是程砚原来的师傅，经值班安排参与当前现场工作。涉及他本人的2019年历史责任由独立岗位复核。林岚负责值班和工单联络，现场电话显示通讯卡；送电许可、设备检修和事故认定由相应岗位依职责办理。

每章保留新的关键住户或家属，师徒两人一直随队。程砚负责判断与复核，季宁从“照片怎么存”成长到独立核查原页、纠正判断和读回后续事项。正文统一使用程砚第一人称“我”，对白保留随口吐槽和岗位生活。

## 职业如何参与剧情

- 接单、报告到场、确认产权和工作范围。
- 正常供电故障按程序处置，具备条件后及时恢复。
- 专业作业落实许可、隔离和相应监护，未知来源继续单列。
- 仪表、有效采集事件、历史队列、住户口述各自核对。
- 工单、图纸和历史档案取得授权，来源、日期和接收人可追查。
- 用户家电、物业公共设施与电网侧资产按产权或合同分工。
- 私人遗物由本人决定提供范围，家属说明经正式渠道接收。

这些流程在人物对话与选择里体现，不编写可照搬的现场操作步骤。详见 [剧情合理化与时间线](STORY_RATIONALIZATION.md)。

## 核心叙事循环

接到报修 → 核对常规原因 → 发现剩余矛盾 → 取得现场与档案证据 → 匹配时序、物件与原职责 → 完成当班工作 → 未解现象留下新记录。

错误选择可被负责人或队友阻止，后果来自误分类、误结工单和责任错接。保持玩家犯错、回看和重试的空间，不靠实施危险操作推进恐怖桥段。

## 视觉与界面

固定机位、湿旧城、青灰与钨丝灯色；成年人物半写实立绘。新抢修车提供师徒出车、整理资料和回程的共同空间。

八名角色有立绘与 Q 版档案。Q 版仅用于人物目录，正剧仍用成年立绘。主角、徒弟有表情变化，老周有现场防护版本。远程联络与历史照片各有清晰标记。文字、仪表数据、证据与交互由应用提供，生成图片不承担精确解谜信息。

PWA 与 Tauri 共用前端和剧情。桌面、手机横屏及竖屏保持阅读与调查可用，自动阅读在调查、推理、结局与面板处停下。

## 世界观边界

异常有独立的未解部分，不能全部归为设备老化或住户心情。家传讲究由人物自己说明，仪式与供电条件分开。原图虚线跨不同供电分区，是资料与人员核对路径；L03、N04与最后联络的时刻需要另排，不按这条圈推事故先后。

许守成2019年遇难，获救者继续生活，沈衡今年因病去世。第一部把救援经过、老周虚假完成和资料漏交写清楚，具体事故原因与责任仍由独立复核。未能确定新通知由谁发送，记录接收也不等于异常全部消失。师徒始终是城区抢修员工，后续案件仍从实际报修进入。
