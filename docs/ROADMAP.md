# 《回路》开发路线

## v0.1.x — 闭合前

目标：证明核心玩法成立。

- [x] PWA + Tauri 2 双端骨架
- [x] 16:9 横屏 UI
- [x] 序章《十三户》最小可玩流程
- [x] 场景调查、证据记录、推理分支
- [x] 本地存档
- [x] 项目 / 美术 / 剧情规范
- [ ] 将硬编码剧情拆分为数据驱动章节
- [ ] 补真实背景图、角色立绘、音效与环境音乐
- [ ] 增加自动播放、历史记录、文本速度与音量设置
- [ ] 增加章节选择与多存档槽

## v0.2 — 《十三户》完整化

目标：把当前 5–10 分钟原型扩成 30–45 分钟完整序章。

- 完整抢修流程与同事通讯
- 槐荫巷住户角色
- 旧宅七年前事件
- 3–5 个场景热点调查
- 2 个错误结局 + 1 个标准结局
- 首个总线伏笔
- 正式 UI / 背景 / 立绘 / 音频资产

## v0.3 — 第一章《头七》

目标：验证章节式生产管线可以复用。

- 新地点、新关键人物
- 复用调查 / 证据 / 推理系统
- 加入时间规律型谜题
- 建立章节内容模板与资产命名规范

## v0.4–0.6 — 主线成形

- 《回送》
- 《长明》
- 《零线》
- 跨章节证据与城市线路图
- 角色关系持续变化

## v0.7–0.9 — 产品化

- 完整设置、存档、无障碍与输入适配
- PWA 离线体验完善
- Windows 安装包与自动 Release
- 性能、资源压缩、自动测试
- 章节一致性检查

## v1.0 — 《回路》第一部

目标：形成一部可以独立发行的中短篇作品。主线完成第一次“闭合”，同时保留继续扩展单元事件的能力。
