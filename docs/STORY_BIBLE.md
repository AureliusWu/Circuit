# 剧情与世界观规范

## 固定前提

- 城市：架空城市“梧城”。
- 主角：梧城供电公司基层配电运检员，兼参与故障抢修。
- 结构：单主角 + 每章不同关键人物。
- 章节：单元剧表面独立，暗线逐渐拼成“城市级回路”。

## 世界观表达方式

不在前几章直接解释“鬼是什么”。玩家只观察到：死亡、执念、仪式和记忆偶尔会借现实网络留下可测量痕迹。

电网是主角能接触到的那一层，所以异常会优先表现为：

- 不合理负荷
- 倒送电
- 无源带电
- 固定时刻跳闸
- 不存在的户号
- 图纸与现场不一致
- 电量与人口、时间、死亡记录之间的异常对应

## 写作规则

每章必须具备：

1. 一个普通人也能理解的现实矛盾。
2. 一个来自职业流程的关键证据。
3. 一个与人物关系有关的民俗线索。
4. 一个在结尾可以重新解释前文的核心事实。
5. 一个不完全解决的余波。

角色不能只为“讲鬼故事”存在。异常应该暴露人的关系：亏欠、隐瞒、遗弃、悔恨、利益或无法告别。

## 主线暗线

每次事件关闭后，都可能留下户号、线路编号、时间戳、坐标或旧档案编号。它们在单章里只是噪声，但跨章节会逐渐构成一个覆盖梧城旧城区的闭环。

“闭合”在本作中同时指：

- 电气回路闭合
- 仪式完成
- 一段关系得到终点
- 某个本不该完成的东西被重新接通

## 语气

克制、具体、生活化。专业词汇可以出现，但不要炫技。真正恐怖的句子通常应短于解释它的句子。
