# v1.9.0 · 十三号回声与回路未眠

接入两首本地原创纯音乐《十三号回声》《回路未眠》，覆盖标题和既有章节氛围；《取号》的专属事件曲继续保留。曲目复用现有音乐音量、暂停恢复和离线缓存，不改变剧情、证据、谜题、旧存档或人物录音。源音符 JSON、MIDI、合成脚本、运行 OGG、摘要和乐器库许可均归档，见 production/MUSIC-INTEGRATION-20261024.md。

修复新增音乐说明缺少“创”“纯”字形的问题，使用原许可 Noto Sans SC 源字体重建子集，保留字体来源摘要与验证记录。项目验收标准按调查 / 证据 / 推理 AVG 制定，正文实际为十章、428 节点和50条证据；第一部六章完结，第二部四章仍连载，本版不宣称全篇完结。

Windows 安装器与 Web/PWA 使用同一提交。必须通过 Windows 实际安装、启动、阅读、保存重开与卸载，十章真实 UI 通关、离线与更新回归，以及公开附件全字节回读后才公开发行。真人试听、完整阅读节奏、实体设备和最终创作验收仍按实际证据分别记录，构建成功不代替这些结论。

本轮亦补齐发行器实际读取的本版本说明路径，避免只存在 docs/releases/ 下的音乐日志而阻断发布。已公开旧版本与标签不改写。
