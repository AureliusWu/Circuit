## 已实现的系统

调查热点与确认记录、证据门槛、多步推理、错误结局重试；六章顺序解锁与重玩、城市线路档案；独立自动进度和三个手动槽、JSON 导入导出、v0.1.0 / v0.1.1 只读迁移；历史日志、键盘与弹窗焦点管理。

阅读设置包括文字速度、自动阅读停留、音量、静音、高对比和减少动态效果。自动阅读不代选调查、谜题或结局，打开面板、返回标题、隐藏页面时暂停。声音只在用户手势后创建，使用原创程序合成的音乐、雨声、电流声和记录提示。

六幅场景与六名成年人物为项目原创静态 SVG；192/512 PWA 图标来自项目原图标的栅格化。美术文件无远程引用、外部字体、企业标识或第三方素材包。具体目录见 [ASSETS.md](ASSETS.md)。

## 发行与平台边界

Web 包采用固定 ZIP 元数据，对相同 `dist` 重复打包得到相同字节与 SHA-256。解压后使用 HTTP 服务；PWA 安装需 HTTPS 或 localhost，首次加载完成缓存后支持离线游玩。

项目为原生 Windows CI 提供 NSIS 构建工作流。本次 Linux 云环境已实际验证 GNU 目标的交叉编译与安装器生成，未远程运行该 CI。安装器不做代码签名；本次 Linux 云环境不具备原生 Windows 安装、升级、卸载与 WebView2 运行验收条件，这些仍需在 Windows 上检查。前端浏览器回归不能代替原生运行验收。

`release.yml` 仅生成可下载工作流附件；公开发布由维护者选择具体版本与渠道。发布前可结合真人反馈校准难度与演出，选择代码签名策略。

## Windows 发行文件

`artifacts/circuit-windows-x64-1.0.0-setup.exe`（4237562 字节），校验文件为同名 `.sha256`。

```text
6d5167053babd358ba8687bab9947b911e02bf52d5516d0e11da4192bd03ecd5  circuit-windows-x64-1.0.0-setup.exe
```

实际使用固定 Rust 依赖、离线模式与 `tauri/custom-protocol`，交叉编译 x64 Windows GUI 载荷并生成 NSIS 安装器。最终嵌入前端与生产回归版本一致。安装器通过内容测试和提取；`WebView2Loader.dll` 与构建目录版本字节一致，PE 导入不存在未随包提供的 GNU 运行库。安装器提取的程序与最终构建程序仅有 Tauri 预期的三个字节打包标记差异。

当前云环境的复现入口为 `bash /workspace/.circuit-env/build-windows-final.sh`。它先核对三个前端文件哈希、只清理项目输出并保留依赖，然后重新编译和打包；编译工具与 NSIS 来自带签名验证的 Debian 包，Tauri 插件保留哈希校验。

两个发行文件的总清单为 `artifacts/SHA256SUMS.txt`，自动验证摘要为 `artifacts/validation.json`。Web 解压后需 HTTP 服务；Windows 安装器需原生 Windows 后续验收，当前未签名。
